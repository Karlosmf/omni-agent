# Stack Tecnológico

El proyecto está construido utilizando las últimas tecnologías del ecosistema de Laravel y desarrollo moderno:

- **Lenguaje:** PHP 8.5
- **Framework:** Laravel 12.x
- **Panel Administrativo:** FilamentPHP v4 (con soporte para validación avanzada y tablas relacionales)
- **Frontend Reactivo:** Livewire v3 + Volt v1 (Single File Components)
- **Framework de Estilos:** TailwindCSS v4
- **Testing:** PestPHP v4
- **Generación de Reportes PDF:** Barryvdh DomPDF
- **Motor de Inteligencia Artificial:** API de Google Gemini (SDK HTTP nativo)
